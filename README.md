# Reelhouse (OTT app in React)

Run locally:

    npm install
    npm run dev

Put it on GitHub Pages:

1. Create an empty repo on GitHub and push this project to the `main` branch.
2. In the repo, open Settings > Pages and set Source to "GitHub Actions".
3. Push again (or run the workflow from the Actions tab). The site goes live in about a minute.

Edit the `TITLES` array in `src/OttApp.jsx` to use your own videos.
